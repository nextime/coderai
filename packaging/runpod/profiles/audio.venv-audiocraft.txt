# A SECOND venv inside the audio image, for audiocraft alone.
#
# audiocraft pins torch==2.1.0, torchvision==0.16.0 and torchtext==0.16.0. The
# server runs torch 2.11 built for a specific CUDA, and torch 2.1.0 has no build
# for that CUDA at all — so installing audiocraft beside the server does not
# merely risk a conflict, it leaves the pod with no working GPU torch. Its own
# venv is the only way both can be right.
#
# Baked at build time, not on first use: a pod is disposable and rented by the
# second, so paying minutes of GPU rental to pip-install a library on every cold
# start would cost more than the image layer does.
--extra-index-url https://download.pytorch.org/whl/cu121
torch==2.1.0
torchaudio==2.1.0
audiocraft==1.3.0
