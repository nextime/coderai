# Extra packages for the MiniMax-H3 venv.
#
# This venv is an OVERLAY: codai/api/h3_worker.py creates it with
# --system-site-packages and installs only what follows, so torch, transformers and
# everything else are inherited from the server's venv. That keeps it ~75 MB
# instead of the several GB a standalone copy of torch costs, and keeps exactly one
# torch on the machine.
#
# Why an overlay at all: H3 exists only as Modular Diffusers blocks
# (MiniMaxH3Blocks / MiniMaxH3ModularPipeline) added in diffusers 0.40, while the
# server runs 0.38 — and upgrading in place changes output for models that are fine
# as they are (measured: Z-Image drifts, mean |diff| 0.0146, while SDXL is
# bit-identical). diffusers is imported once per process, so the split only has to
# be per-process.
#
# This file is used ONLY when CODERAI_H3_STANDALONE_VENV=1 forces a fully
# independent venv — needed if the parent's torch is ever too old for H3.
